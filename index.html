ABOUT ME

I build navigation software that has to work beyond the simulator.

My graduate work is centered on robot navigation in manufacturing environments. I am especially interested in how global planning, localization, terrain information, and robot software interfaces must fit together before a path becomes real motion.

03SUPPORTING
