NAVIGATION

Can the robot reach the goal?

This project connects global localization, path generation, path following, velocity command generation, and the low-level locomotion interface into one ROS2 navigation pipeline.

IMPLEMENTATION DETAILS

The front page says Navigation. The details explain how.

Global Planning

A custom ROS2/Nav2 global-planner path generates collision-aware routes on the navigation map. The implementation includes 8-connected search, cost penalties, corner-cut prevention, path reconstruction, smoothing, and heading generation.

  • Custom A* plugin
  • Costmap-aware traversability
  • nav_msgs/Path output

Path Following

The navigation stack converts the planned path into robot velocity commands through a path-following controller. The focus is stable forward/yaw motion first, before exploiting full lateral legged-robot mobility.

  • Regulated Pure Pursuit
  • /cmd_vel generation
  • Goal / progress checking

Robot Interface

ROS velocity commands are bridged into the robot's LCM command channel and consumed by the low-level learned locomotion controller.

  • ROS2 → LCM bridge
  • Deadman timeout
  • Velocity saturation / sign policy

Safety & Integration

Manual joystick control and autonomous navigation are separated because both can publish to the same low-level command channel. TF, footprint, inflation, and timestamp consistency are treated as system-level safety conditions.
