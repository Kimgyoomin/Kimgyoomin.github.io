Scope: this is a deterministic browser demonstrator of the V0 planning contracts and baseline parameters over a synthetic terrain. It ports the terrain gates, Wavefront ring expansion, merge/neighbor radii, edge sampling precedence, slope-risk edge cost, and graph A* behavior for explanation. For browser responsiveness, the synthetic layer explorer uses local finite-difference proxies for slope and roughness; the authoritative ROS2 C++ implementation estimates these surfaces with local PCA. The 3D viewer visualizes that same synthetic elevation field and does not represent robot dynamics. It does not execute the ROS2 node, consume live FastDEM data, or claim robot-calibrated limits.

IMPLEMENTATION DETAILS

Terrain interpretation first. Search second.

Terrain Evaluation

FastDEM elevation cells are reconstructed as a regular terrain snapshot. Local surface geometry is evaluated before a node or edge is accepted.

  • 5 cm elevation lattice
  • PCA slope / roughness in the ROS2 implementation
  • Strict observed-support checks
  • Explicit consecutive-height step checks

Wavefront Roadmap + A*

A deterministic FIFO roadmap expands ring proposals around accepted nodes, validates each candidate and edge, merges nearby samples, creates loop edges, and connects the goal before A* searches the accepted graph.

RRT* Comparison

The ROS2 package also contains a separate RRT* mode using nearest → steer → choose-parent → insert → rewire under the same TerrainEvaluator contract. The interactive V1 focuses on the default Wavefront mode.

Lifecycle & Revalidation

Changed height maps recheck the active path corridor. Confirmed invalid paths are cleared and replanned while stale results are prevented from replacing newer state.

CURRENT LIMITS

Prototype, not a safety claim.

Not robot-calibrated yet

The 15° slope and 8 cm step values are software bootstrap thresholds. Physical experiments are still required for reliable step-up/down, forward-slope, cross-slope, and support limits of RUBI.

Browser demo vs. ROS2 runtime

The interaction is intentionally explanatory. The authoritative implementation remains the C++ ROS2 package, its tests, and real FastDEM/RViz experiments. A future version can replay exported planner snapshots or run the core through WebAssembly.
