# Portfolio media slots

This directory is reserved for curated portfolio media only.

Recommended filenames:

- `localization_rviz.mp4` — RViz localization / map alignment / trajectory
- `localization_robot.mp4` — real robot localization sensing run
- `navigation_rviz.mp4` — RViz goal, global path, path tracking
- `navigation_robot.mp4` — real robot autonomous navigation
- `terrain_waveplanner.mp4` — height map, sampled graph, rejected terrain, final path

Recommended export contract:

- MP4 / H.264
- 1920×1080 or 1280×720
- 30 fps
- 8–25 seconds per clip
- no audio unless it adds technical value
- crop terminal clutter and unrelated desktop UI
- show one technical point per clip
- prefer captions inside the website rather than baked into the video

Do not commit large raw rosbag recordings or unedited experiment videos here. Use short, curated clips for the public portfolio.
